## Why

El README actual describe principalmente el stack y la estructura interna, pero comunica poco el problema que Tobimarks resuelve y el flujo de uso del producto. Esta mejora debe ayudar a una persona visitante a entender el producto antes de llegar a la información técnica.

## What Changes

- Reorganizar el README alrededor de la propuesta de valor y del recorrido de usuario.
- Documentar el problema, el funcionamiento y las funcionalidades observables de Tobimarks.
- Añadir una sección visible para screenshots y demos, preparada para enlaces o imágenes reales.
- Explicar la organización asistida por IA y sus límites actuales sin inventar comportamiento.
- Incluir un ejemplo rápido de uso.
- Separar la referencia de API, instalación local, arquitectura y stack en secciones técnicas posteriores.
- Documentar seguridad, limitaciones conocidas y licencia con información verificable.
- Corregir afirmaciones desactualizadas o no respaldadas por el repositorio.

## Capabilities

### New Capabilities

No aplica. Este cambio actualiza documentación y no modifica comportamiento del producto.

### Modified Capabilities

No aplica. `skip_specs: true` porque no cambia requisitos observables.

## Impact

- `README.md` será reescrito y seguirá siendo el punto principal de entrada del repositorio.
- No se modifican código de aplicación, API, dependencias ni contratos de backend.
- Las screenshots y demos se documentarán como espacio preparado; no se agregarán recursos inexistentes.
